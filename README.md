# Password Strength Checker (Python)

## About

This is a simple Python program that checks the strength of a password based on its length and character types.

## Features

* Checks password length
* Detects uppercase and lowercase letters
* Detects digits and special characters
* Classifies password as Weak, Medium, or Strong

## Tech Used

* Python

## How to Run

1. Run the Python file
2. Enter a password
3. View the strength result
